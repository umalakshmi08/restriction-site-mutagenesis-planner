Progress Made

The core bio-logic for the planner is built. Given a DNA sequence and a restriction enzyme, the program validates the DNA, looks for the restriction site, makes a simple one-base mutation, and checks whether the site was eliminated.

Core Logic

  1. Take the DNA sequence and enzyme as input.
  2. Validate that the DNA contains only A, T, G and C.
  3. Identify the selected restriction site.
  4. Change one base at that location.
  5. Verify that the restriction site was removed.

Testing

Code

Run with: python3 mutagenesis_planner.py

sites = {"EcoRI": "GAATTC", "BamHI": "GGATCC", "HindIII": "AAGCTT"}

dna = input("DNA sequence: ").upper()
enzyme = input("Enzyme (EcoRI/BamHI/HindIII): ")

if set(dna) - set("ATGC"):
    print("Invalid DNA sequence")
elif enzyme not in sites:
    print("Invalid enzyme")
elif sites[enzyme] not in dna:
    print("Restriction site not found")
else:
    site = sites[enzyme]
    pos = dna.find(site)
    new = dna[:pos] + "C" + dna[pos + 1:]

    print("Original:", dna)
    print("Mutated: ", new)
    print("Position:", pos + 1)

    if site not in new:
        print("Restriction site removed")
    else:
        print("Restriction site still present")
